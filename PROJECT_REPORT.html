1. Executive Summary & Architectural Overview

In standard software development practices, running 24/7 Kubernetes (Amazon EKS) clusters in non-production environments generates massive cloud budget drain (often exceeding $160 to $300 USD per cluster monthly).

The Ephemeral Solution: This project establishes an automated, end-to-end Ephemeral Infrastructure Pattern. All underlying cloud networking (Multi-AZ VPC, Subnets, Internet Gateway, and NAT Gateway), Kubernetes control plane (EKS v1.30), worker compute (Managed Node Groups on EC2), and containerized microservices are provisioned on-demand via Terraform. Once demonstration and automated testing are complete, the entire environment is cleanly destroyed.

7. FinOps Governance & Teardown Execution

To conclude the ephemeral lifecycle, an automated teardown sequence was executed. In Kubernetes architectures on AWS, deleting the cluster before deleting the LoadBalancer service causes orphaned ELBs and ENIs that block VPC deletion and continue generating charges.

Safe Teardown Protocol Executed:

  1. Deleted Kubernetes Service to trigger immediate AWS ELB deprovisioning.
  2. Allowed 60 seconds for ENI detachment from VPC subnets.
  3. Executed terraform destroy -auto-approve to terminate EC2 nodes, EKS control plane, NAT gateway, and VPC.
  4. Deleted the Amazon ECR repository using AWS CLI.

Final Financial Verification: All 22 resources were confirmed deleted. The running EC2 instance count was confirmed as 0, active EKS clusters as 0, and active NAT gateways as 0, securing a 100% zero recurring cost outcome.
